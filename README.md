# Jetson Nano – Documentación y Desarrollo

Repositorio de trabajo con la tarjeta de desarrollo **NVIDIA Jetson Nano**, creado como parte de mi proyecto de grado. Aquí encontrarás documentación, ejemplos de código y recursos útiles que fui recopilando durante mi estudio y desarrollo de proyectos con esta poderosa tarjeta.

---

## 🧠 ¿Qué es la Jetson Nano?

La Jetson Nano es una computadora de bajo consumo diseñada por NVIDIA, pensada para aplicaciones de inteligencia artificial, visión por computadora, robótica y más. Está equipada con una GPU potente para su tamaño y una serie de pines GPIO para diferentes aplicaciones.
